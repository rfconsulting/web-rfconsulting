# Iteración: jerarquía de Servicios Web

## Decisión

“Proyectos” y “Aplicaciones web” dejan de competir con “Servicios web” en la navegación principal. Ambos representan evidencia o capacidades internas de esa oferta y se presentan como secciones de `/servicios-web`.

## Implementación

- Navegación principal reducida a Nosotros, Especialidades, Servicios web, Conocimiento y Contacto.
- Navegación contextual dentro de Servicios web hacia `#servicios`, `#proyectos` y `#aplicaciones`.
- Caso resumido de aplicaciones web integrado en la página principal de Servicios web.
- Enlaces del pie y del home dirigidos a las secciones correspondientes.
- Las páginas `/proyectos` y `/aplicaciones-web` se conservan como vistas ampliadas para mantener enlaces existentes, profundidad de contenido e indexación.
- Las vistas ampliadas marcan Servicios web como sección activa en el encabezado.
